# Prática de Estudos em Java

Repositório dedicado aos meus estudos de Java, com exercícios, exemplos e resoluções de atividades desenvolvidas durante o aprendizado de programação.

## Conteúdo

Os arquivos estão organizados em pastas dentro de `src/`:

- **`Exemplos/`** — exemplos introdutórios e testes de entrada de dados.
- **`Lista02/`** — exercícios com classes e objetos, incluindo exemplos de estudantes, contas bancárias, círculos, temperaturas e relógios.
- **`Praticando/`** — sequência de exercícios práticos de programação.
- **`Questoes/`** — questões numeradas para praticar lógica e conceitos da linguagem.
- **`ListadeExercicios01.java`** e **`ResolucaoLista02.java`** — arquivos com resoluções de listas de exercícios.

## Tecnologias

- Java
- Programação orientada a objetos
- IntelliJ IDEA (estrutura de projeto presente no repositório)

## Como executar

1. Instale o JDK (Java Development Kit).
2. Clone ou baixe este repositório.
3. Abra o projeto em uma IDE compatível com Java, como IntelliJ IDEA, ou configure o projeto manualmente.
4. Abra o arquivo `.java` que deseja estudar.
5. Execute a classe que contém o método `main`, quando aplicável.

**Observação:** alguns exercícios podem depender de outras classes do mesmo diretório. Verifique os imports e os nomes dos pacotes antes de executar cada atividade.

## Objetivo

Praticar os fundamentos de Java, desenvolver o raciocínio lógico e registrar minha evolução por meio de exercícios acadêmicos e pessoais.
